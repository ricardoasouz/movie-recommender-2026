# movie-recommender-2026

Containerized movie recommender (Feb 2026 stack): FastAPI API, offline training pipeline, Postgres, CI, reproducible builds.


***A reproducible, containerized movie recommendation system built with a modern Feb-2026 Python stack:* **

***- FastAPI for serving,***

***- a separate offline training pipeline,***

***- PostgreSQL for metadata/logging,***

***- and CI for quality gates.***

## “Technologies (Feb 2026)” ##

* **Python 3.12+**
* **FastAPI + Uvicorn** (API)
* **Docker + Docker Compose**
* **PostgreSQL 16** (metadata, request logs, experiments)
* **Ruff** (lint + format)
* **Pytest** (tests)
* **Pydantic** (config + validation)
* **Redis** (cache)
* **MLflow** (experiment tracking)
* **OpenTelemetry** (tracing)
* **pre-commit**
* **GitHub Actions**
